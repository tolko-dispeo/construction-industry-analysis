# Construction Industry Analysis

Анализ финансового состояния российских компаний, занимающихся строительством жилых и нежилых зданий.

В проекте собраны и проанализированы данные бухгалтерской отчетности строительных компаний за 2021–2025 годы.

## Что сделано

- Отобраны малые и средние юридические лица с основным видом деятельности  
  **41.20 — строительство жилых и нежилых зданий**.
- По ИНН компаний собраны данные бухгалтерской отчетности из БФО ФНС.
- Выполнена очистка и подготовка данных с помощью `pandas`.
- Проанализирована динамика:
  - выручки;
  - чистой прибыли;
  - прибыли от продаж;
  - рентабельности;
  - доли прибыльных компаний.
- Рассчитаны финансовые показатели:
  - Current Ratio;
  - Interest Coverage Ratio (ICR);
  - отношение обязательств к собственному капиталу.
- Проведен анализ структуры расходов и финансовой нагрузки.
- Построены графики и визуализации для сравнения показателей по годам.
- Для сопоставления динамики использована постоянная выборка компаний, имеющих отчетность за весь рассматриваемый период.

## Данные

Для формирования выборки использовались данные реестра компаний и бухгалтерская отчетность БФО ФНС.

После первоначальной фильтрации было отобрано около 9 тыс. компаний.  
Для анализа динамики использовалась сбалансированная выборка из **6386 компаний**, имеющих данные за каждый год с 2021 по 2025.

## Основные результаты

В исследуемой выборке в 2021–2023 годах наблюдался рост ряда финансовых показателей.

С 2024 года динамика части показателей ухудшается: при дальнейшем росте номинальной выручки снижается чистая прибыль и доля прибыльных компаний, ухудшаются показатели покрытия процентов и ликвидности, а отношение обязательств к собственному капиталу растет.

Период ухудшения части финансовых показателей совпадает с периодом высоких процентных ставок и изменениями в ипотечной поддержке. При этом анализ носит описательный характер и не устанавливает причинно-следственную связь между этими факторами.

## Ограничения

- Денежные показатели представлены в номинальном выражении и не скорректированы на инфляцию.
- Использование постоянной выборки обеспечивает сопоставимость годов, но может создавать survivorship bias.
- Макроэкономические факторы используются для контекста и не рассматриваются как доказанные причины изменения финансовых показателей.
